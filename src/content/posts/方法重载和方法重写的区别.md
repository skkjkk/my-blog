方法重载和方法重写都是 Java 中多态特性的体现，但它们的方向完全相反：重载发生在**同一个类内部**，是编译期的静态多态；重写发生在**父子类之间**，是运行期的动态多态。

方法重载指的是在同一个类里定义多个**方法名相同但参数列表不同**的方法。判定重载只看参数列表，参数列表包括参数个数、参数类型以及参数的排列顺序，方法名相同而参数列表不同就是重载，与返回值类型和访问修饰符都没有关系 —— 如果方法名相同、参数列表也相同，只是返回值不同，那在 Java 中是编译不过的。编译器在编译期就能根据实参确定调用哪一个重载方法，所以重载属于静态绑定。

方法重写指的是子类对父类中**已有的方法**重新实现，要求方法签名保持一致，也就是方法名和参数列表都相同，同时子类方法的访问权限不能比父类方法更严格，返回值类型要么相同，要么是协变返回即父类返回类型的子类。final 修饰的方法不能被重写，static 修饰的是静态方法属于隐藏而不是重写，private 方法因为子类不可见同样不构成重写。重写体现的是子类对父类行为的定制，运行时由实际对象的类型决定调用哪个实现，也就是动态绑定。

:::tip
一句话总结：重载是同一个类里方法的横向扩展，重写是父子类之间行为的纵向替换。
:::
