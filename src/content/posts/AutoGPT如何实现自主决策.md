AutoGPT 是 2023 年引爆"自主 Agent"概念的代表性开源项目。它的核心机制是**把 LLM 放进一个"思考—行动—观察"的循环里，并让它自己决定下一步做什么**，同时配套了一整套让 Agent 能在真实环境中干活的工程外壳。

1) **核心循环就是 Agent Loop**。每一轮：把当前任务、已有记忆、可用的命令与结果喂给模型 → 模型输出"思考（Thought）+ 选定的命令（Command）" → 框架**真正执行**该命令（文件操作、代码执行、网页访问、Shell 等）→ 把执行结果作为观察（Observation）回填 → 进入下一轮，直到模型判定任务完成。**模型负责"想"，框架负责"做"** —— 这条分工至今仍是所有 Agent 框架的范式。

2) **"自主"体现在命令空间的开放性**。AutoGPT 给模型的不是固定的几个业务函数，而是**一整套通用操作原语**（读写文件、列目录、执行代码、搜索网页、发 HTTP 请求、发起 API 调用）。**动作空间越大，模型可组合出的行为就越自由**，这正是它"通用"的来源，也是它最容易失控的原因。

3) **记忆机制是它能跑长的关键**。项目内置了一套**短期与长期记忆体系**：短期记忆用**向量数据库**保存历史记录并做**语义检索**（只取回与当前任务相关的那几条，而不是全量塞进上下文）；长期记忆用**知识图谱**存储实体与关系，支撑"我之前提过的那家公司"这类跨任务关联推理。**这是 AutoGPT 在"上下文窗口装不下"这个核心难题上的早期解法。**

4) **"连续模式"体现自治程度**。它支持三种运行模式：**单步**（执行一个命令后停下等指令）、**连续**（自主循环直到完成）、**连续-限制**（连续执行但达到 token 消耗上限就停）。**这个设计至今仍是所有 Agent 的"自主度档位"范式。**

5) **工程外壳让它"能干活"**。**沙箱与执行环境**（Docker 隔离、代码执行器、浏览器实例）、**文件管理**（虚拟文件系统与工作区）、**LLM 能力抽象层**（可换模型与配置）、**配置驱动**（YAML 定义 Agent 的角色、目标、可用命令、模型参数、循环上限）、**Web 界面**（可视化看循环、看日志）。

6) **它暴露的问题，正好定义了后来所有 Agent 工程的研究方向**。**① 上下文膨胀** —— 每轮把全部历史喂回去，成本线性甚至超线性增长、注意力被稀释；**② 目标漂移** —— 长链条中逐渐偏离原始目标；**③ 错误级联** —— 早期错误成为后续每步的前提；**④ 循环与失控** —— 反复执行同类命令、烧掉预算；**⑤ 缺乏验收** —— 靠模型自述"完成了"，实际没做成。**后来出现的 ReAct、Reflexion、Plan-and-Execute、规划-执行分离、记忆外置、预算守卫、程序化验收，全都是在解 AutoGPT 暴露的这些问题。**

7) **它的历史意义大于当下实用价值**。它证明了"**给模型一个通用动作空间 + 一个循环 + 一套记忆，就能涌现出复杂行为**"，同时证明了这条路的**可靠性瓶颈不在模型能力，而在上下文管理与工程约束**。后续 AutoGPT 自身也转向了更工程化的方向（Graph、Forge 等形态），迭代重心从"更自主"变成"**更可靠、更可观测、更可交付**"。

8) **面试怎么答**。核心是三句话：**① 自主来自"通用命令空间 + 思考行动循环"；② 它靠向量检索的短期记忆 + 知识图谱的长期记忆突破上下文限制；③ 它最大的贡献是暴露了长程任务的四大顽疾（上下文膨胀、目标漂移、错误级联、缺乏外部验收），这些正是今天 Agent 工程的全部重点。** 第三点最能体现你不只是知道它是什么，而是理解它推动了行业。
