内部类是指**定义在另一个类内部的类**，从源码层面看它虽然写在外部类的花括号里，但编译后会生成独立的 class 文件，所以它本质上还是顶层类，遵循 Java 只能单继承的规则，并不会因为写在内部就变成内部类可以多继承。

按照定义位置，常见的内部类有四种。成员内部类定义在外部类的成员位置，可以直接访问外部类的所有成员，包括 private 修饰的私有成员，不需要加任何修饰符。静态内部类用 static 修饰，不依赖外部类的实例，因此只能访问外部类的静态成员。局部内部类定义在方法内部，作用域仅限于所在方法。匿名内部类则是在创建对象的时候临时定义的，没有名字，一般用来一次性实现某个接口或者覆盖某个方法。

内部类最大的价值是**访问外部类的私有成员**。在 Java 中，外部类同样可以访问内部类的所有成员，这是由编译器生成访问器这种字节码层面的机制实现的，所以内部类经常被用来实现一些只服务于外部类的辅助逻辑，这样既能隐藏实现细节，又能把相关代码聚在一起，提升可读性。

实际工程中内部类最常见的用途是**实现回调和事件监听**。比如给按钮注册点击事件时，匿名内部类可以把处理逻辑直接写在调用现场，不需要为只使用一次的行为单独建一个类。另外在并发编程中，用内部类配合匿名 Runnable 或者 Callable 来提交任务，以及在流式处理中用 lambda 或者匿名内部类来表达映射和过滤逻辑，都是非常自然的写法。

需要注意的是，因为内部类隐式持有外部类的引用，如果外部类比较大而且生命周期很长，这种引用关系会造成额外的内存占用，在涉及内存敏感的场景或者做缓存时需要留意。
