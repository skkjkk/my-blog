让 Agent 具备长期记忆，本质上是做一套**"写入决策 — 检索决策 — 遗忘决策 — 冲突治理"**的完整记忆系统，而不是简单地"把对话存起来"。

1) **写入：先筛再存**。用四个信号决定一条信息是否值得写入：**新颖性**（与已有记忆是否重复）、**重要性**（对未来任务的参考价值）、**置信度**（用户显式陈述还是模型推断）、**可复用性**（是可泛化规律还是一次性事件细节）。写入时做**原子化事件抽取** —— 把自然语言拆成独立、可判定真伪、带时间戳与实体的事实单元，而不是整段对话塞库。每条记忆必须带元数据：来源、置信度、时间戳、有效期、作用域、实体链接。

2) **存储方案按内容形态分层**。**语义记忆（事实与知识）** → **向量库 + 结构化数据库**双写，向量做语义召回、字段做过滤与去重；**情景记忆（任务轨迹）** → **事件日志 / 时序库 / 对象存储**，按时间与任务 id 检索；**程序性记忆（经验与规则）** → **知识库 / 知识图谱 / 规则文件**，可版本化可审阅；**工作记忆** → **上下文 + 外部 scratchpad**（临时文件、KV 存储）。另可加**知识图谱**承载实体关系，支撑多跳推理与实体对齐。

3) **检索：多路召回 + 重排**。单一向量检索在长记忆库上召回质量会明显下降，标准做法是并行做：**语义向量召回**（表达相近的表述）、**关键词检索**（专有名词、编号、错误码的精确匹配）、**结构化过滤**（作用域、实体、时间窗口的硬约束）、**图关系扩展**（一跳或两跳的关联），最后用**交叉编码器或模型重排**。重排后再做**上下文预算管理**：按 token 预算截断、低优先级内容摘要压缩、**高价值信息放在提示首尾**（规避长上下文中段注意力衰减）、按时间加权衰减。

4) **遗忘：成本控制而非删除**。三种机制：**时间衰减**（生存期或半衰期）、**容量淘汰**（按价值与访问频率组合分淘汰）、**冗余压缩**（语义高度重叠的记忆聚类合并）。关键原则是**遗忘不等于抹除** —— 被淘汰的旧事实应**归档**而非物理删除，保留演进轨迹让冲突有据可查。同时要把**删除权交给用户**（查看、编辑、清除），这是长期使用建立信任的前提。

5) **冲突治理：统一原则 + 双向检测**。三类冲突：同一事实槽位不同取值、不同来源结论矛盾、新旧偏好并存致行为不确定。解决原则按优先级：**时间优先** → **权威性优先**（用户显式陈述 > 模型推断）→ **作用域优先**（更具体覆盖更宽泛）→ **置信度优先**（同时保留冲突记录）；解决不了就**保留双版本并在适当时机澄清**。检测必须**读写两侧都做**：写入时查既有记忆是否矛盾，检索时查同批结果是否互相打架。

6) **记忆的"可追溯"能力**。每条记忆要能回答三个问题：**谁说的**（来源与授权）、**什么时候说的**（时间戳）、**凭什么信**（置信度与证据）。这三点是记忆系统可审计、可纠错的前提，也是防止"记忆投毒"的基础。

7) **工程化的配套**。记忆要能被**度量**：写入量、命中率、检索延迟、被引用率、冲突发生率、失效淘汰率、**记忆对任务成功率的实际贡献**（可用消融实验：关闭记忆看成功率掉多少）。**没有这些数据，记忆系统就无法迭代优化。**

8) **常见反模式**。把整段对话直接当记忆（噪声大、不可检索）；只做写入不做遗忘（库无限膨胀、召回质量下降）；把记忆当成"万能知识库"塞满无关内容（**稀释注意力比没有记忆更糟**）；不做冲突检测（同一件事两条矛盾记忆，模型行为不确定）。
