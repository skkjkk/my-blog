这是一篇示例文章，可以直接改掉或删掉。下面简单说三件事。

## 1. 怎么发新文章

打开 `app.pagescms.org`，用 GitHub 登录，选你的仓库 → 左侧「文章」→「新条目」。

填标题、网址短名（英文，比如 `my-first-post`）、发布日期，正文直接在里面写。写完点右上角保存，你的仓库里会多一个文件，网站几分钟后自动更新。

## 2. 支持哪些写法

**加粗**、*斜体*、`行内代码`、[链接](https://astro.build)。

## 3. 一个提醒

后台的编辑器是可视化编辑，适合写普通文字。上面那种 `:::note` 提示块、数学公式 $E = mc^2$ 这类进阶语法，建议直接在 GitHub 网页上编辑文件，更稳。
