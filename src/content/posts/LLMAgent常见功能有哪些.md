LLM Agent 的常见功能可以按"**能力形态**"归为九类，每一类都有明确的实现要点与典型场景。

## 对话与问答增强

。在传统 RAG 之上加入**多轮澄清、反问、答案溯源、拒答与转人工**。实现要点是**意图澄清**与**证据溯源**：不确定就反问而不是猜，答案要能指回来源。

## 检索增强问答（RAG）

。文档问答、客服知识库、企业制度查询、内部知识检索。关键能力是**多路召回 + 重排 + 引用标注 + 时效性判断**，以及**检索不到时的明确拒答**。

## 工具调用与 API 编排

。调用外部 API 完成查询、写入、事务、通知。核心是**工具描述质量、参数校验、错误回填让模型自我纠正、并行调用降低延迟**。

## 多步骤任务执行（工作流自动化）

。填表、报表生成、数据同步、批量处理、审批流转。关键能力是**任务分解、状态持久化、断点恢复、幂等**—— 流程长的任务必须支持从任意步骤续跑。

## 代码辅助与工程化

。代码生成、解释、审查、重构、修复、测试编写、CI 排障。关键能力是**读写代码库、执行与验证代码、基于真实编译/测试结果迭代**。

## 数据分析与洞察

。自然语言查数、报表解读、趋势分析、异常归因。关键能力是**把意图翻译成查询、把结果做成结构化表格与图表、区分相关与因果**。

## 计算机操作与 GUI 智能体（Computer Use）

。操作浏览器与桌面应用完成表单填写、网页操作、跨应用协作。关键能力是**屏幕感知（截图解析）、坐标定位、动作执行与结果确认、失败重试**。这类任务对**可靠性要求极高**，因为误操作代价大。

## 多 Agent 协作

。按主管式、链式、并行、路由、辩论等模式组织多个角色分工协作。关键能力是**任务契约、上下文隔离、结果汇总与冲突处理**。

## 长期记忆与个性化

。记住用户偏好、历史决策、领域知识，提供个性化服务。关键能力是**写入筛选、检索排序、遗忘淘汰、冲突治理**，以及**用户可见可控**（能查看与删除）。

## 规划与自主决策

。复杂目标的分解与执行，包括**分层规划、树搜索、反思改进**。关键能力是**规划与执行分离**、**外部验收**、**局部重规划**。

## 生产运维与排障

。告警响应、故障定位、自动化修复。这是最能体现 Agent 价值的场景，因为**排障路径无法预先穷举**，但也最需要**人在环**与**强审计**。

## 贯穿所有功能的三项通用能力

。**流式输出**（提升感知体验）、**人在环**（关键节点请求确认）、**多模态**（图像、语音、屏幕理解）。**这三项不是可选功能，而是决定 Agent 好不好用的体验基础。**

## 功能选型的判断依据

。判断某个需求该不该用 Agent，看三点：**步骤是否可预先确定**（可确定就用工作流）、**是否需要与环境交互**（不需要就用普通调用）、**错误的代价是否可控**（代价高就必须加强校验与人在环）。
